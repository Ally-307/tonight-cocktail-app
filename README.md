# 今夜调酒 —— 口袋调酒 App

原生 HTML/CSS/JS 调酒台 + Android WebView 离线壳。34 款特调随机抽取（自动避开上一杯）、
杯量换算、逐步调配指引、搜索与收藏；黑紫琥珀原创视觉系统，酒品图统一便利店夜拍风格。

- 技术栈：HTML / CSS / JavaScript（零构建依赖）+ Android Java WebView（Gradle）
- Android v1.5.0 已构建验收（见 Release APK），网页资源全部内置、无需联网权限
- Web 版部署于 Netlify；UI 回归采用本机 Edge 隔离式自动化截图测试

## 目录
- `src/` Web 应用源码
- `android/` Android WebView 壳工程（Gradle）

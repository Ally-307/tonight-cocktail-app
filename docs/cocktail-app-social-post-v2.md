# 家里调酒最难的，不是摇杯

你有没有过这种晚上：桌上有半瓶基酒，冰箱里有柠檬、汽水和一些说不清能不能用的材料，想认真调一杯，最后却因为不知道“这些到底能做什么”，又默默打开了啤酒。

很多调酒工具默认你已经知道自己要喝什么。

「今夜调酒」想解决的，恰恰是决定之前的那几分钟。

打开 App，首页没有先扔给你一整面酒单，只有一个大摇杯。点开它，四张调酒票据才依次出现：随机抽一杯、按材料匹配、浏览酒单、查看收藏。

如果你手头只有几样东西，就选出最多 5 种材料，让 App 从 34 款配方、47 种原材料里按匹配程度给出答案。选定之后，再切换杯量，跟着步骤加冰、摇匀、搅拌。它离线可用，也不索取权限，手机可以安静地放在吧台边，只负责告诉你下一步做什么。

它当然不能把厨房变成酒吧。

但它能把“家里就这些”，变成“那今晚就调这一杯”。

调酒的仪式，不必从懂酒开始。它也可以从承认自己手里有什么开始。

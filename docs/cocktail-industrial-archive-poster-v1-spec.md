# 今夜调酒｜工业档案风宣传海报 v1

## 交付目标

- 画布：1080 × 1350 px，4:5 社交平台主图。
- 产品：Android 调酒 App「今夜调酒」v1.5.0。
- 设计模式：Field Archive Poster（现场档案海报）。
- 核心叙事：从手头材料出发，经材料匹配与逐步调制，完成今晚的一杯。

## 视觉系统

- 六列隐性栅格，左侧 108 px 永久档案轨道。
- 主色：炭黑 `#0A0D0B`、暖纸白 `#F2ECDF`、信号琥珀黄 `#E9A92C`。
- 中央主体为原创不锈钢摇杯工程图，包含真实功能对应的三段标注：打开功能票据、最多选择 5 种材料、逐步调制。
- 右侧使用当前版本真实首页截图作为界面证明，避免把海报做成纯氛围图。
- 大号裁切英文、微型等宽标签、测量线、十字定位点、条码和档案编号共同建立工业记录感。

## 已验证文案与数据

- `34 RECIPES`
- `47 ITEMS`
- `UP TO 5`
- `ZERO PERMISSIONS`
- `ANDROID 7.0+`
- `VERSION 1.5.0`
- `RECIPE ARCHIVE / 配方档案`
- `MATERIAL MATCH / 材料匹配`
- `STEP MODE / 逐步调制`
- `OFFLINE / 离线可用`

## 原创与品牌边界

- 未使用鹰角网络、明日方舟、罗德岛或任何阵营的 Logo、角色、图标、口号、URL 与专有字体。
- 借鉴范围限定为可迁移的高对比栅格、双语索引、工业注释与档案编排语法。
- 摇杯图形、产品标记和版式均为本项目原创。

# 今夜调酒｜层级窗口重构预览 v1

## 反馈转译

本轮不把问题理解为“卡片不够好看”，而是把它拆成四个结构问题：

1. 二级任务全屏覆盖，父层消失，层级来源不清楚。
2. 匹配结果与配方使用相近宽度和标题权重，视觉重合度过高。
3. 配方内的酒款下拉允许在子层横跳同级内容，违反“从列表进入详情、再返回列表”的层级逻辑。
4. 步骤推进会重绘整个配方并执行 `scrollTop = 0`，变化发生后用户被送回顶部，看不到下一步。

## 新结构

采用可见路径与逐级缩小窗口：

`摇杯 → 功能分类 → 结果/酒单 → 配方 → 步骤操作舱`

- 父层以顶部档案带持续露出；每深入一层，当前窗口的上下左右边距增加、圆角减小、标题字号降低、信息密度提高。
- 顶部同时显示返回父级、`L2–L4` 层级编号和当前位置路径。
- 材料页在选择区内直接预告“下一层：匹配结果”，说明解锁条件与排序逻辑。
- 匹配结果保留材料父层，配方窗口保留匹配结果父层。
- 删除配方内酒款下拉框；更换酒款必须返回来源列表，返回后仍停留在原来的材料/酒单上下文。
- 步骤改成配方窗口底部的固定小型操作舱，只更新操作舱内容，不重绘配方，不修改滚动位置。
- 当前步骤同时显示下一步名称，例如 `NEXT / 加入液体`，让变化发生前就可预期。

## 动效规则

- 前进：内容短距离向右退出，新层以裁切与位移进入。
- 返回：内容向左退出，恢复父层窗口。
- 步骤推进：只对步骤操作舱执行 130ms 淡出、轻微下移和模糊切换。
- 不使用弹簧、漂浮和持续运动；系统开启减少动态效果时立即切换。

## 纸面颜色修订

- 原票据米白 `#F1EBDD` 在深色层级窗口中亮度过高，容易被误读为独立白色弹窗。
- 第一轮将配方摘要、票据和步骤舱统一改为烟熏灰绿纸 `#C3C6BA`，悬停纸面使用 `#D0D2C7`。
- 纸面次级文字改为深灰绿 `#46514C`，实测正文对比度为 `4.76:1`。
- 柑橘黄继续只表示当前杯量、层级编号、步骤进度和主要操作，不扩大颜色占比。

## 配方摘要暗色统一

- 根据“莓果晚风和暗色统一颜色”的反馈，酒款摘要从烟熏灰绿纸改为配方父层使用的墨绿黑 `#1C2522`，增加一条低对比细边线，不再形成大块浅色矩形。
- 酒款标题使用暖白 `#F7F4ED`，分类与风味使用钢灰绿 `#9CA8A3`；实测对比度分别为 `14.30:1` 与 `6.39:1`。
- “返回酒单换一杯”改为暗色透明按钮，文字对比度 `9.29:1`；底部步骤操作舱继续保留烟熏灰绿纸，作为当前真正的下一层小窗口。

## 验收结果

- 390×844：材料、匹配、配方、步骤四个状态均完成真实点击截图。
- 320×700：无横向溢出，可见按钮均不小于 44×44 px，层级编号与完整路径仍可辨认。
- 步骤推进前后：任务层滚动位置 `0 → 0`，配方内部滚动位置 `0 → 0`。
- 浏览器控制台：错误与警告为 0。
- Impeccable layout detector：`[]`，无机械布局问题。
- 本轮仅修改网页源文件与生成预览图，未同步 Android assets，未构建 APK。

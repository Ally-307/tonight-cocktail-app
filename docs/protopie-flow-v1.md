# ProtoPie 交互蓝图 v1

## 核心流程

```text
Shaker idle
  → Tap shaker
  → Shaker pressed + ticket reveal
  → Feature picker
  → Select task
  → Task surface
```

## 关键交互

### 1. 摇杯入口

- 点击区域：整个摇杯与其底部标签。
- 反馈：摇杯向点击方向倾斜约 6°，金属边缘出现一次短暂高亮；不连续摇晃。
- 进入：四张功能票据以错位、短距离的顺序展开。
- 返回：再次点击摇杯或点击返回，票据收回并恢复待机状态。

### 2. 功能票据

- 默认折叠：显示图标、标题、一个简短解释。
- 触摸后展开：显示完整点击区域和辅助说明。
- 选择后：票据保留一次按压状态，再进入对应页面。

### 3. 页面过渡动画

- 首页 → 任务层：首页整体后退并降低透明度，任务层从轻微下移和内缩状态展开到全屏。
- 时间：主过渡 420 ms；任务内容内部切换先 140 ms 淡出，再进入新内容。
- 缓动：使用 `cubic-bezier(0.16, 1, 0.3, 1)`，表现为快速响应、慢速落稳。
- 功能票据：四张票据按 70 / 120 / 170 / 220 ms 逐项进入，不做循环摇晃。
- 酒单 → 配方：点击酒款时先保留选中态，再过渡到对应配方；`晚樱之吻` 和 `海盐日出` 必须进入各自步骤。
- 减少动态效果：系统开启 Reduce Motion 时，跳过内容淡出等待，直接切换状态。

### 4. 逐步调制

- 当前步骤固定在视口内可见。
- 点击“完成这一步”后，当前票据盖章为完成状态，下一步上移。
- 不使用自动连续播放；每一步必须由用户确认。
- 减少动态效果时，直接切换步骤状态。

# Stark 与 Maze 验证计划 v1

## Stark 检查项

- 正文与背景对比度达到 WCAG AA。
- 主按钮文字与背景达到 AA，不能只用柑橘黄小字表达信息。
- 所有触控目标至少 48×48px。
- 摇杯、票据、材料标签和步骤状态具备可读的辅助标签。
- 键盘焦点顺序：品牌区 → 摇杯 → 四张票据 → 底部操作区。
- reduced motion 下不丢失状态和流程反馈。

## Maze 任务

1. 不看说明，找到“随机抽一杯”。
2. 使用手头材料匹配出一款可调酒品。
3. 从酒单找到一款收藏酒并打开配方。
4. 将配方切换为双杯用量。
5. 完成前两步调制并返回首页。

## 成功指标

- 首次用户 10 秒内能找到一个功能入口。
- 随机抽酒任务完成率 ≥ 90%。
- 材料匹配任务中，用户不需要返回首页寻找入口。
- 逐步调制过程中，用户能明确识别“当前步骤”和“完成状态”。
- 记录因票据命名、摇杯可点击性或返回路径产生的误解。

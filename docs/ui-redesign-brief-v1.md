# 今夜调酒 UI 重设计 Brief v1

## 目标与用户

- 目标用户：普通人在家调酒的人，可能只知道手头有什么材料，不熟悉专业酒名或调酒术语。
- 使用场景：夜间、家庭吧台或采购后单手使用手机，边看步骤边操作。
- 主要任务：快速找到今晚能调的酒，并按清晰步骤完成调制。
- 成功标准：用户打开 App 后，不需要先理解酒单结构；点击一级入口即可找到合适的功能。

## 已确认的信息架构

```text
大摇杯首页
└── 点击摇杯
    └── 功能入口
        ├── 随机抽一杯
        ├── 按手头材料匹配
        ├── 浏览酒单
        └── 查看收藏
            └── 配方详情
                └── 杯量 / 原料 / 风味 / 调配步骤
```

## 一级界面原则

- 首页只保留一个强主入口：大摇杯。
- 摇杯不是装饰图，而是可点击、可反馈、可返回的导航对象。
- 首页首屏不展示 34 款酒的密集列表，不让用户先做分类学习。
- 点击后以清晰的功能入口呈现全部能力，功能不删减，只改变进入方式。
- 动效服务于“打开摇杯、进入今晚调酒流程”，不能让用户等待或迷失。

## 必须保留的能力

- 34 款酒品与配方数据
- 随机抽酒
- 按最多 5 种材料匹配配方
- 酒单浏览与搜索
- 收藏
- 杯量换算
- 风味、原料和逐步调制
- 音效开关与 Android 顶部、底部安全区适配

## Figma 页面清单

1. 首页：大摇杯待机状态
2. 首页：点击摇杯后的入口展开状态
3. 首页：摇杯反馈与入口收起状态
4. 功能选择：四个主功能入口
5. 随机抽酒：抽取中、结果揭晓、进入配方
6. 材料匹配：材料选择、已选状态、匹配结果
7. 酒单：搜索、筛选、酒款列表
8. 收藏：空状态、已收藏列表
9. 配方详情：杯量、原料、风味、步骤
10. 逐步调制：当前步骤、完成反馈、重新开始
